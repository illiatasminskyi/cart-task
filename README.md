# Cart Task

Laravel додаток для управління кошиком покупок.

## Розгортання через Docker

### Передумови

- Docker (версія 20.10 або вище)
- Docker Compose (версія 2.0 або вище)

### Кроки розгортання

1. **Клонування репозиторію**

   ```bash
   git clone <repository-url>
   cd cart-task
   ```

2. **Налаштування змінних середовища**
   - Скопіюйте файл `.env.example` в `.env`:
     ```bash
     cp .env.example .env
     ```
   - Відредагуйте `.env` файл і налаштуйте наступні параметри:
     ```
     APP_NAME="Cart Task"
     APP_ENV=local
     APP_KEY=  # Залиште порожнім, буде згенеровано автоматично
     APP_DEBUG=true
     APP_URL=http://localhost:8080

     DB_CONNECTION=mysql
     DB_HOST=db
     DB_PORT=3306
     DB_DATABASE=laravel
     DB_USERNAME=laravel
     DB_PASSWORD=password

     # Інші налаштування за потребою
     ```

3. **Запуск контейнерів**

   ```bash
   docker-compose up --build -d
   ```

4. **Генерація ключа додатку**

   ```bash
   docker-compose exec app php artisan key:generate
   ```

5. **Запуск міграцій бази даних**

   ```bash
   docker-compose exec app php artisan migrate
   ```

6. **Запуск сидерів**

   ```bash
   docker-compose exec app php artisan db:seed
   ```
   - Це додасть тестових користувачів (test@example.com / password) та товари.

7. **Збірка фронтенд ресурсів**

   ```bash
   docker-compose exec app npm run build
   ```

### Доступ до додатку

- Веб-додаток: `http://localhost:8080`
- phpMyAdmin (адмінка БД): `http://localhost:8081`
- База даних: localhost:3306 (зовнішній доступ, якщо потрібно)


### Запуск тестів

Для запуску тестів у Docker-контейнері використовуйте команду:

```bash
docker-compose exec app php artisan test
```

### Корисні команди

- **Перегляд логів:**

  ```bash
  docker-compose logs -f
  ```

- **Зупинка контейнерів:**

  ```bash
  docker-compose down
  ```

- **Перезапуск контейнерів:**

  ```bash
  docker-compose restart
  ```

- **Виконання команд в контейнері додатку:**

  ```bash
  docker-compose exec app <command>
  ```

- **Очищення (видалення контейнерів, мереж та volumes):**

  ```bash
  docker-compose down -v
  ```

### Структура контейнерів

- **app**: PHP-FPM контейнер з Laravel додатком
- **web**: Nginx веб-сервер
- **db**: MySQL база даних
- **phpmyadmin**: phpMyAdmin для управління базою даних

### Налаштування

- Nginx конфігурація: `docker/nginx/conf.d/default.conf`
- Docker Compose: `docker-compose.yml`
- Dockerfile: `Dockerfile`

### Troubleshooting

- Якщо порт 8080 зайнятий, змініть в `docker-compose.yml`
- Перевірте логи контейнерів при помилках
- Переконайтеся, що `.env` файл правильно налаштований

## Резюме

### Характеристика коду

Код проекту побудований відповідно до принципів SOLID, що забезпечує його гнучкість, розширюваність та підтримуваність. Основна бізнес-логіка винесена у сервіси, а робота з базою даних — у репозиторії. Це дозволяє легко тестувати та розширювати функціонал.

Код стабільний для використання у невеликих та середніх проектах. Для забезпечення ще більшої стабільності можна додати кешування запитів до бази даних та впровадити систему моніторингу помилок.

### Що можна покращити

#### Додати функціонал промокодів

Промокоди дозволять користувачам отримувати знижки на товари у кошику. Для реалізації цього функціоналу можна:

1. Створити таблицю `promo_codes` з полями:
   - `code` (унікальний код промокоду),
   - `discount` (розмір знижки у відсотках або фіксована сума),
   - `expires_at` (дата закінчення дії),
   - `usage_limit` (максимальна кількість використань).

2. Додати валідацію промокоду при його введенні:
   - Перевірка наявності коду в базі.
   - Перевірка терміну дії та ліміту використань.

3. Інтегрувати з кошиком:
   - Розрахунок знижки при застосуванні промокоду.
   - Відображення знижки у підсумковій сумі кошика.

4. Додати інтерфейс для введення промокоду на сторінці кошика.

Цей функціонал підвищить залученість користувачів та дозволить легко впроваджувати маркетингові кампанії.

### Кешування даних

Кешування дозволить зменшити навантаження на базу даних і прискорити роботу додатку. Наприклад, можна кешувати список товарів, підсумкову суму кошика або популярні запити. Для цього можна використовувати Redis або вбудовану систему кешування Laravel.

### Розширення функціоналу кошика

1. **Функція "Обране" для товарів**
   - Додати можливість позначати товари як "Обрані". Це дозволить користувачам швидко знаходити улюблені товари.
   - Реалізувати таблицю `favorites` з полями: `user_id`, `product_id`.

### Покращення UX

1. **Ajax для оновлення кошика**
   - Використовувати Ajax для додавання, видалення та оновлення товарів у кошику без перезавантаження сторінки. Це покращить взаємодію користувача з додатком.

2. **Повідомлення про успішні дії**
   - Відображати повідомлення про успішні дії (наприклад, "Товар додано до кошика" або "Кількість оновлено"). Це можна реалізувати через спливаючі повідомлення (toasts).

### Моніторинг та логування

Впровадження системи моніторингу, наприклад, Sentry, дозволить відстежувати помилки у реальному часі. Це допоможе швидко реагувати на проблеми та покращувати стабільність додатку.

### Оптимізація продуктивності

1. **Використання індексів у базі даних**
   - Додати індекси до ключових полів (наприклад, `user_id`, `product_id`), щоб прискорити виконання запитів.

2. **Оптимізація запитів**
   - Використовувати `eager loading` для зменшення кількості запитів до бази даних. Наприклад, завантажувати товари разом із їх категоріями або іншими пов’язаними даними.
